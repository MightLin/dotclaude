# Skill：撰寫 design-guide.md

## 目的
讓 Claude 產出的 UI 程式碼符合專案既有的視覺規範與元件使用慣例。

## 必要內容

### 1. 使用的 UI 套件與版本
### 2. 佈局規範（grid、spacing、container 寬度）
### 3. 元件使用慣例
哪些元件對應哪些使用情境。

### 4. 禁止事項
不允許使用的元件或做法。

### 5. 表單規範
驗證時機、錯誤訊息顯示方式。

## 範例
```markdown
# Design Guide
最後更新：YYYY-MM-DD

## UI 套件
{套件名稱與版本}

## 佈局
- 主內容區最大寬度：{寬度}
- 間距系統：{說明}
- 卡片元件：{使用規範}

## 元件慣例
- 資料列表：{元件名稱}（使用情境）
- 選單：{元件名稱}（單選 / 多選）
- 對話框：{元件名稱}（使用情境）
- 通知：{元件名稱}（使用情境）

## 禁止
- 不使用原生 HTML 表單元素，一律用 UI 套件對應元件
- 不使用 inline style

## 表單規範
- 驗證觸發時機：{說明}
- 錯誤訊息顯示方式：{說明}
```
