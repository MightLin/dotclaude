# Stitch Design Rubric

## 門檻
- 總分（加權）≥ 80
- 任一維度 ≥ 70
- 上述兩者皆滿足才視為 PASS

## 維度與權重

| 維度 | 權重 | 評分要點 |
|---|---|---|
| 需求符合度 | 40% | 是否涵蓋 brief 列出的所有系統功能；資訊架構是否反映業務流程；缺漏關鍵頁面/操作直接 < 70 |
| 視覺一致性 | 20% | 是否與專案既有 `design-guide.md` 一致（色彩、字級、間距、元件選用）；無既有 design-guide 則此項權重併入需求符合度（變 60%） |
| 可用性 / accessibility | 25% | 資訊層級清晰、操作路徑短、對比度、鍵盤可操作、ARIA 標註合理 |
| 實作可行性 | 15% | 能用專案既有 UI 套件（design-guide.md 標示者）實作，無依賴稀有元件或自訂繁複動畫 |

## 計分

```
total = score_需求 × 0.40
      + score_視覺 × 0.20  // 無既有 design-guide 時併入需求 → 0.60
      + score_可用 × 0.25
      + score_實作 × 0.15
```

每維度 0–100。
